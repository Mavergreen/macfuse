# macFUSE for Mavericks

[macFUSE](https://macfuse.github.io) 5 for Mac OS X 10.9 Mavericks.

## Usage

Running macFUSE 4? This will replace it.
Running osxfuse 3? Remove it first.

1. Install [Recaulk](https://github.com/Mavergreen/recaulk/releases)
2. Install this
3. Use a wide variety of FUSE file systems
